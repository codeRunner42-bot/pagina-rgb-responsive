¿Qué son las Media Queries?

Las media queries son una funcionalidad de CSS3 que permite aplicar estilos dependiendo de las características del dispositivo, como el tamaño de la pantalla.

Con las media queries, puedes diseñar interfaces responsive sin depender exclusivamente de frameworks como Bootstrap. Son clave para el diseño moderno.
